# Food Delivery Customer Behavior Analytics Dashboard

## Overview
This project is an interactive Power BI dashboard analyzing 50K+ food delivery orders to understand customer behavior, cuisine trends, delivery performance, and business insights.

## Tools Used
- Power BI
- DAX
- Excel/CSV

## KPIs
- Total Orders
- Total Revenue
- Average Rating
- Average Delivery Time
- Repeat Customer %

## Dashboard Features
- Orders by City
- Cuisine Popularity
- Orders by Time
- Delivery Time vs Customer Rating
- Interactive Filters

## Key Insights
- Evening orders are highest
- Mumbai & Pune contribute maximum orders
- Repeat customers account for nearly 50% of orders
- Premium restaurants maintain better customer ratings
